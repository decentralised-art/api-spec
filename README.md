# decentralised.art API Specification

## decentralised.art - API Contracts & Schemas

This repository contains the **canonical API specifications** for
**decentralised.art**.

Clients, SDKs, and tools **consume these specifications** to guarantee
consistent behavior across the entire ecosystem.

Specs are grouped by public API, then endpoint group. The current chain API
contracts live in `apis/chain/<group>/openapi.yaml`.

## Purpose

This repository serves as the **single source of truth** for:

- REST API definitions
- Public API endpoint groups
- Versioned OpenAPI specifications
- Shared data models and schemas
- Code generation for SDKs (C++, TS, Rust, Python)
- Backwards-compatibility assurance
