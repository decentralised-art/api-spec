# Tools for decentralised.art API Specification

Utilities for validating, bundling, and generating SDKs for
**decentralised.art**.

The `tools/` directory contains all auxiliary scripts and configuration files  
required to maintain API consistency, perform contract linting, validate  
OpenAPI structure, and automate SDK code generation.

These tools run locally and inside CI pipelines to keep decentralised.art API contracts
consistent.
